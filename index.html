How to change a redirect

1
Open config.js in any text editor
2
Change QR1_URL or QR2_URL to your new destination URL
3
Save the file, then run git add . && git commit -m "update redirect" && git push
4
Done — your QR codes now point to the new URL. No reprinting needed!
